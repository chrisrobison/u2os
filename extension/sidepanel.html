U2OS form filler

Pair this browser with your U2OS on this computer. Run npm run u2 -- job extension pair and enter the code it prints.

Ready to fill

    Nothing is waiting. Plan and review an application in U2OS first.

    Settings

    Off by default. When on, and only if U2OS is in live mode and every field was filled with confidence, the extension records its intent with U2OS, presses the form's submit button and reports what the board said. If it cannot tell, the outcome is marked uncertain and never retried. When off, you press submit yourself.
