Runtime ownership (#264): a dedicated local SQLite exclusive guard is acquired before application migration/reconciliation, with canonical-home alias handling and no lease expiry. Started HTTP handlers and background work drain before release; disconnected clients do not permit premature replacement. An idempotent shutdown method and observable closed promise support isolated fixtures. Duplicate-process, interruption/uncertain-action, failed bootstrap, alias/independent-home, fresh/demo/legacy and unknown-file/symlink fixtures exercise the boundary. Only successfully owned guard artifacts are excluded from fresh-demo emptiness checks. Existing records and queue semantics remain intact. Maintenance/backup coordination, cross-host/restored-copy safety and useful provider deadlines remain unfinished; no live validation was performed.

Startup bind safeguard (#262): queue, sync and trigger workers start only after successful HTTP bind; bind rejection cleans prepared device adapters. Isolated occupied-port fixtures preserve queued rows and zero attempts in fresh/configured personal homes, clear heartbeat resources and leave another running home's workers intact; successful-bind/close fixtures retain configured timers. Worker-setup failure after bind closes the listener and drains partial setup. An idempotent internal background drain does not close HTTP or cancel pending request handlers. Local initialization can still precede binding. Cross-process singleton/maintenance locking, complete runtime shutdown and safe backup/restore remain unfinished.

Sync lifecycle (#260): same-home/domain/provider/account polling and manual calls share one in-flight operation, including sanitized failures. Other accounts/domains/homes stay independent; reconciliation preserves work without catch-up retries. An awaited timer shutdown drains already-started operations without claiming cancellation. Deterministic entry/release and captured-timer fixtures cover overlap, switches, failures, retries, stale callbacks and success/failure drain. This is a recovery prerequisite, not yet a complete runtime/maintenance lock or safe live backup; no live sync validation was performed.
